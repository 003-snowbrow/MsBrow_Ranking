美睫師考核排名

依每月薪資單「一部考核總表」的達標率排序，並列出當月客數、新客、入會、現場預約、IG 分享與 Google 好評。

完整排名

點欄位標題可排序；點美睫師名字可在下方趨勢圖中追蹤（最多 5 位）。

逐月趨勢

淺灰線為所有美睫師；點線條或表格中的名字可加入追蹤。底色標示目前選擇的月份。

達標率 = IG分享 + 新客Google好評率 + 新客入會率 + 現場預約率（或客量）+ 紀錄照上傳率，各項滿分 20%。

更新考核資料

  1. 在 Google 試算表開啟當月薪資單，選 檔案 → 下載 → Microsoft Excel (.xlsx)。
  2. 把檔案拖到下方或點選檔案。網頁只讀「一部考核總表」第 3 列（D 欄起）的名字與各項數據，檔案不會離開你的瀏覽器。
  3. 確認月份與預覽後按「套用並下載 data.json」。畫面會立即更新，並下載一份用目前密碼加密好的 data.json。
  4. 把下載的 data.json 覆蓋到網站專案裡的同名檔案（見下方「如何發布」），其他人打開網址就會看到新月份。

    如何發布到網站（覆蓋 data.json）
    1. 打開網站專案 GitHub 專案頁，點進 data.json，按右上角鉛筆旁的「⋯」→「Upload files」或直接按「Edit」貼上內容，再按 Commit changes。 2. 約一分鐘後網站就會更新。重新整理網頁即可看到。 3. 嫌麻煩也可以把 .xlsx 或 data.json 直接交給 Claude，請它更新網站。
    變更密碼
    輸入新密碼後會下載一份用新密碼加密的 data.json；覆蓋到網站後，所有人就要用新密碼才能進入。
